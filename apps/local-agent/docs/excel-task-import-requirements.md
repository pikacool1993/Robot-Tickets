# 飞书 CSV 导入 local-agent 创建任务需求

更新日期：2026-11-27。状态：**已实现，桌面操作与真实账号匹配待验收**。

原 Excel 导入方案已调整为「飞书多维表格统计客户预定 → 导出 CSV → local-agent 导入并创建任务」。本文汇总当前确认结果，沿用原文档文件名。

## 1. 业务流程

1. 代理商通过飞书多维表格登记客户预定，导出客户需求总表 CSV。
2. 在 local-agent 选择 CSV，解析创建任务所需字段并逐行预览。
3. 预览标出可导入、已关联、疑似重复和校验失败的记录。
4. 代理商确认后，可先导入校验通过的行，疑似重复行需要单独确认才创建。
5. 新任务保存预定观演人姓名、座位要求、跨区凑单开关、价格放宽开关及触发秒数，保持待授权。
6. 代理商扫码授权，获取该任务绑定账号的观演人名单，并按姓名匹配。
7. 全部预定观演人匹配并确认后，任务才允许由代理商手动启动。
8. 导入完成后提供回填任务 ID 的 CSV，保留原始客户信息及未成功导入记录。

每行对应一组预定和一个任务，观演人为 **1 至 2 位**，姓名用空格分隔。购票张数必须为 1 或 2，且与观演人人数一致。

## 2. CSV 字段范围

最新样例《足球登记_数据表_表格.csv》包含 21 列、8 条记录，使用 UTF-8 BOM。

```csv
观演人,购票张数,登记类型,任务ID,场次,状态,座位要求类型,指定区域,指定票类,按层选择,允许跨区凑单,按价格放宽区域,开票后自动扩区秒数,客户来源,客户备注,微信号,闲鱼号,小红书号,其他账号,应收,实收费用
```

### 2.1 导入使用的字段

| CSV 字段 | 格式与处理规则 |
|---|---|
| 任务ID | 新预定留空；回填格式为 `{客户端编号}-{任务ID}`，例如 `A01-123`；填写时核对客户端及本机任务，按第 5 节处理 |
| 观演人 | 必填，1 至 2 位姓名，以空格分隔，例如 `张三 李四`。保存为待匹配姓名 |
| 购票张数 | 必填，整数 1 或 2，必须与观演人人数一致 |
| 座位要求类型 | 必填，仅支持 `固定区域`、`指定票类`、`按层选择` |
| 指定区域 | 类型为固定区域时读取，例如 `102 首层看台 ￥180, 109 首层看台 ￥220` |
| 指定票类 | 类型为指定票类时读取，例如 `A类 ￥220, B类 ￥180` 或 `VIP ￥1288` |
| 按层选择 | 类型为按层选择时读取，例如 `首层看台, 顶层看台` |
| 允许跨区凑单 | `1` 开启，`0` 或空白关闭，默认关闭 |
| 按价格放宽区域 | `1` 开启，`0` 或空白关闭，默认关闭 |
| 开票后自动扩区秒数 | 开启价格放宽时必填，为现有任务支持的 0 至 86400 秒整数 |

座位要求类型决定读取三个座位字段中的哪一个，有效类型对应的字段不能为空。

### 2.2 忽略的业务字段

`登记类型`、`场次`、`状态`、`客户来源`、`客户备注`、`微信号`、`闲鱼号`、`小红书号`、`其他账号`、`应收`、`实收费用`不参与创建任务或填写任务配置。

- 任务使用 local-agent 当前配置的场次。
- `首开`、`捡漏`不用于筛选导入记录或决定任务行为。
- CSV 的授权、通知、出票状态不决定是否导入，也不设置客户端真实状态。
- 客户备注不写入任务备注，社交账号不用于协议绑定，费用不参与票价匹配。
- 上述原始字段仍保留在回填 CSV 中，供代理商继续统计。

## 3. CSV 解析要求

- 按表头列名读取，允许列顺序变化。缺少必需字段时在预览阶段提示。
- 使用标准 CSV 解析处理引号、逗号、双引号转义及单元格内换行，兼容 UTF-8 有 BOM 和无 BOM 文件。
- 座位多选值先解析为完整单元格，再按单元格内逗号拆分选项并清理首尾空白。不能将整份文件直接按逗号切开，也不能按空格切开区域描述。
- 观演人按空白分隔；座位多选值按逗号分隔，取代旧 Excel 模板中座位空格分隔的约定。
- 固定区域从选项开头提取编号，兼容 `VIP1`、`VIP2`、`VIP3`，映射为本机目录代码。
- 指定票类从选项中提取票类标识，例如 `A类 ￥220` 映射为 `A`，`VIP ￥1288` 映射为 `VIP`。
- 开关识别 `1`、`0`、空白，其他值在预览中提示错误。价格放宽关闭时，不通过秒数字段隐式开启功能。
- 预览中的错误须定位到对应记录和字段，方便代理商修正。

## 4. 座位配置与目录校验

### 4.1 配置依据

**以 local-agent 当前座位目录为准。** 用区域编号、票类标识或层名称匹配本机目录，CSV 中的描述和金额不覆盖目录。

- 价格、层级描述或「未开售区域」文字与本机目录有差异时，在预览中提示。
- 区域不存在，或本机目录标为不可售时，该行校验失败，供代理商修正后再导入。
- CSV 标注未开售、但本机目录为可售时，按本机目录配置，并显示差异提示。
- 多选区域或票类构成任务候选范围。
- 按层选择时，展开本机目录中所选层的可售区域集合，去重后保存为现有固定区域模式；指定票类保存为现有票类模式。

最新样例已将 127、128、129 区价格改为 ￥400，与本机目录一致。「按层选择」已移除 VIP，只包含首层看台、顶层看台。101、124、128、132 区的「未开售区域」描述与本机可售标记仍有差异，按上述规则处理。VIP 可通过指定票类或指定 VIP 区域表达。

### 4.2 跨区凑单和价格放宽

- 跨区凑单按任务对应开关应用，默认关闭。
- 价格放宽默认关闭，关闭时始终按原座位配置匹配。
- 价格放宽开启后，触发前按原配置匹配；到达开票后指定秒数，以原配置中全部候选区域的最低价和最高价为边界，匹配该价格区间内的区域，持续到任务结束。
- 运行期间手动关闭价格放宽后，恢复按原配置匹配。

## 5. 任务 ID 与重复导入

| CSV 情况 | 预览与处理方式 |
|---|---|
| 任务 ID 留空，配置有效 | 标为可导入，确认后创建新任务 |
| 任务 ID 对应本机已有任务 | 标为已关联，跳过该行，不覆盖已有任务配置 |
| 任务 ID 的客户端编号与当前客户端不同 | 提示客户端编号不一致，不关联同号本机任务，不创建任务 |
| 任务 ID 在本机不存在 | 提示核对，不创建任务 |
| ID 留空，但观演人和座位配置与本机已有任务相同 | 标为疑似重复，由代理商单独确认是否仍创建 |
| 必需信息或座位配置无效 | 标为校验失败，显示具体原因 |

支持部分导入。失败行留待修正，疑似重复行经明确确认后才创建。预览显示记录位置、观演人、转换后的配置及处理结果。

兼容此前导出的纯数字任务 ID，仍按本机已有任务核对。新建任务回填统一使用带客户端编号的格式；客户端编号本身包含 `-` 时，以最后一个 `-` 分隔任务编号。

## 6. 新建任务与授权后匹配

### 6.1 配置应用

新任务保存预定观演人姓名及人数、座位要求、跨区凑单、价格放宽及触发秒数。导入完成后保持待授权，由代理商扫码并手动启动购票。

已有任务 ID 的记录按已关联规则跳过。

### 6.2 观演人匹配与启动限制

- 获取名单后，只在该任务绑定的微信账号中按预定姓名匹配。
- 姓名唯一匹配时自动选中；同名或找不到时显示「观演人待确认」并指出对应姓名。
- 代理商可补录观演人、刷新名单或手动选定，解决待确认项目。
- **全部预定观演人匹配并确认后，才允许启动。** 购票张数与最终确认的观演人人数须一致。
- 例如 `张三 李四` 只匹配到张三时，李四仍需人工处理，不能仅按张三一人启动。
- 任务启动时继续执行现有授权、业务就绪和座位配置校验。

## 7. 导出回填 CSV

- 导入完成后提供一份回填任务 ID 的 CSV。
- 仅对成功创建的记录填写 `{客户端编号}-{任务ID}`，客户端编号取当前登录编号。已有任务 ID、失败行和跳过行保留原值。
- 保留原始列及列顺序、客户信息、空字段和未成功导入的记录。
- 修正失败行后，可用同一份 CSV 再次导入。本机能找到的已有任务 ID 会自动跳过。
- 代理商保存回填文件。如何将任务 ID 更新到飞书线上表格，尚未约定自动操作。

## 8. 实施边界

当前范围是读取飞书导出的本地 CSV，把预定要求应用到新建的本机任务。任务 ID 和重复判断均以本机任务为范围。

核心业务规则与本轮实现见下节。成功记录可回填，失败记录可修正重试；再次导入时根据本机任务 ID 与配置判断，避免重复创建。

## 9. 已实现入口与保存行为

- 任务页搜索框左侧提供「导入任务」，打开窗口后通过「选择 CSV」读取文件。预览按行显示观演人、座位、跨区与价格放宽配置、处理结果及目录差异提示。
- 可导入行默认勾选，疑似重复行须逐行勾选「仍创建」。通过「重新校验」获取最新本机任务关联结果。
- 一次选中的有效记录在同一笔本地保存中提交。保存失败时整批不创建，避免生成半配置任务或丢失 ID；代理商仍可单独选择有效行分批导入。
- 创建成功后，预览中的对应行立即变为已关联，点击「导出回填 CSV」保存。文件使用 UTF-8 BOM，保留原始列顺序及每个单元格值。CSV 的引号和换行由标准编码器重新生成。
- 导入源表和回填结果在当前登录的内存中保存，关闭导入窗口后可重新打开继续导出。退出登录或关闭客户端后应使用已导出的回填文件重新导入。
- 本机任务持久化保存预定姓名及张数，任务卡片在待授权时可显示预定姓名，并支持按姓名搜索。授权后的唯一姓名匹配自动选中，同名匹配须手动确认。手动取消部分观演人后，启动校验要求重新选齐预定人数。
- 同一记录中两位同名观演人可以登记，授权后须人工选择两个不同观演人 ID。
- 非当前座位类型的残留字段在预览中提示忽略，仅应用当前类型字段。
- 当前支持 UTF-8 CSV，文件上限 10 MB。表头须包含第 2.1 节所列字段，重复表头或 CSV 结构错误会在预览前提示。
- 对用户提供的最新 CSV 完成解析核验，8 条记录均可转换为任务配置；原始客户字段通过导出、重新读取后的逐单元格一致性检查。
